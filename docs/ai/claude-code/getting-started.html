Claude Code 安装、启动与核心命令速查。

Claude Code 是一个 agentic 编程环境——不同于聊天机器人等你提问，它能主动读取文件、执行命令、修改代码，甚至在你离开时自主完成任务。

斜杠命令

命令说明
/init初始化项目，自动生成 CLAUDE.md
/clear清除当前对话上下文
/compact压缩上下文历史，节省 token
/compact [主题]按指定主题压缩，如 /compact 聚焦 API 改动
/model切换模型（Sonnet / Opus）
/memory管理全局记忆（CLAUDE.md）
/permissions管理权限设置
/hooks配置自动化钩子
/mcp管理 MCP 服务器连接
/export导出对话为 Markdown
/resume恢复历史会话
/rename重命名当前会话
/rewind回退到之前的检查点
/sandbox启用操作系统级沙箱隔离
/plugin浏览和安装插件

CLI 参数

命令说明
claude -p "提示词"非交互式运行，输出结果后退出
claude -c / claude --continue继续最近的会话
claude --resume从历史会话列表中选择恢复
claude --model <模型名>指定使用的模型
claude --output-format json以 JSON 格式输出结果
claude --output-format stream-json流式 JSON 输出
claude --allowedTools "Read,Edit,Bash"限制可用工具（适合批量/CI 场景）
claude --dangerously-skip-permissions跳过所有权限检查（仅在沙箱环境中使用）
claude --verbose调试模式，输出详细信息

快捷键

快捷键说明
Esc中断当前思考/执行
Esc Esc打开 Rewind 菜单，回退到之前检查点
Shift+Tab循环切换权限模式 / 进入 Plan 模式
Ctrl+R反向搜索历史提示词
Ctrl+G在编辑器中打开计划进行编辑
'直接执行 Bash 命令
