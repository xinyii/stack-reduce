处理器类型

类型说明适用场景
command执行 Shell 命令格式化、Lint、日志、安全
promptLLM 单轮 Yes/No 判断任务检查
agent多轮子代理验证运行测试套件
httpPOST 到端点接收 JSON外部系统通知
