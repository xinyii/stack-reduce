上下文管理

用 @ 符号精准引用、Notepads 持久化信息、上下文窗口管理策略与提示词技巧。

上下文是 AI 编码的核心燃料——给 AI 正确的上下文，准确率从 62% 跃升到 91%。掌握上下文管理是用好 Cursor 的关键。

@ 符号：精准上下文引用

在 Chat 或 Composer 中输入 @ 即可唤出上下文引用菜单，支持 8 种引用方式：

引用类型语法说明
文件@filename引用指定文件的完整内容
文件夹@folder/引用整个目录结构和内容
代码块@symbol引用函数、类等代码符号
Codebase@Codebase语义搜索整个代码库，自动找到相关代码
Docs@Docs引用已索引的官方文档（React、Next.js 等）
Web@Web搜索网络获取实时信息（Pro 版）
Git@Git引用最近的 Git 变更、提交历史
Definitions@Definitions自动包含当前文件中符号的定义

Notepads：持久化上下文

Notepads 是 Cursor 独有的功能，用于存储跨会话复用的上下文信息。与 Rules 不同，Notepads 不会自动注入，需要手动通过 @notepad-name 引用。

适用场景

  • 项目架构说明 — 记录核心模块关系、数据流
  • API 接口文档 — 常用接口的请求/响应格式
  • 会议决策记录 — 技术选型、设计决策
  • 复杂业务逻辑 — 用自然语言描述业务规则

创建方式

  1. 打开命令面板（Ctrl + Shift + P）
  2. 搜索 Cursor: Open Notepad
  3. 创建并编辑 Notepad 内容
  4. 在对话中通过 @notepad-name 引用

上下文窗口管理策略

AI 模型的上下文窗口有限，且上下文质量在 20–40% 容量时就开始下降。以下 6 个策略帮助你保持上下文高效：

1. 定期新建会话

一个对话聚焦一个功能或任务。完成一个任务后，新建会话开始下一个，而不是在同一个长对话中继续。

2. 用 @ 符号按需引入

不要一开始就把所有文件丢给 AI，按需引用。让 Agent 模式自主搜索往往比手动添加 20 个文件更有效。

3. Notepads 存储持久信息

把反复需要告诉 AI 的信息写进 Notepads，避免每次重复粘贴。

4. Rules 文件承载项目规范

技术栈、编码风格、架构约束等信息写入 .cursor/rules/，自动注入每次对话。

5. 复杂任务分阶段执行

将大型任务拆分成独立的小任务，每个阶段用新会话。上一阶段的产出（代码文件）自然成为下一阶段的上下文。

6. 代码注释承载决策

在关键代码处用注释记录"为什么这样做"，AI 读取代码时会自动获取这些上下文。
