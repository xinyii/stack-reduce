## 多会话并行

| 方式 | 说明 |
|------|------|
| Agent Teams | 多个 Claude 实例自动协调，共享任务和消息 |
| Claude Code 桌面端 | 可视化管理多个本地会话，每个会话独立 worktree |
| Claude Code Web | 在 Anthropic 云端隔离 VM 中运行 |

## Writer/Reviewer 模式

| 会话 A（Writer） | 会话 B（Reviewer） |
|-------------------|---------------------|
| "为 API 端点实现速率限制器" | — |
| — | "审查 @src/middleware/rateLimiter.ts 中的速率限制器实现，检查边界情况、竞态条件" |
| "这是审查反馈：[B 的输出]。解决这些问题。" | — |

## 批量处理（Fan-out）

```bash
# 批量迁移文件
for file in $(cat files.txt); do
  claude -p "Migrate $file from React to Vue. Return OK or FAIL." \
    --allowedTools "Edit,Bash(git commit *)"
done
```

## CI/CD 集成

```bash
# 在 CI 管道中使用
claude -p "检查这个 PR 的代码质量" --output-format json

# 流式处理
claude -p "分析日志文件" --output-format stream-json | your_command
```
