> Claude Code 是一个 agentic 编程环境——不同于聊天机器人等你提问，它能主动读取文件、执行命令、修改代码，甚至在你离开时自主完成任务。

## 安装与启动

推荐使用 [ZCF](https://github.com/UfoMiao/zcf)（Zero-Config Claude-Code Flow）一键配置完整开发环境：

```bash
# 交互式菜单（推荐，按需选择功能）
npx zcf

# 完整初始化（首次使用，自动完成安装 + API 配置 + 工作流导入 + MCP 设置）
npx zcf i

# 仅更新工作流（保留 API 等核心设置）
npx zcf u
```

安装完成后即可使用：

```bash
cd your-project
claude                        # 启动交互式会话
claude "解释这个项目的架构"      # 带初始提示启动
claude update                  # 更新到最新版本
```

## 斜杠命令

| 命令 | 说明 |
|------|------|
| `/init` | 初始化项目，自动生成 CLAUDE.md |
| `/clear` | 清除当前对话上下文 |
| `/compact` | 压缩上下文历史，节省 token |
| `/compact [主题]` | 按指定主题压缩，如 `/compact 聚焦 API 改动` |
| `/model` | 切换模型（Sonnet / Opus） |
| `/memory` | 管理全局记忆（CLAUDE.md） |
| `/permissions` | 管理权限设置 |
| `/hooks` | 配置自动化钩子 |
| `/mcp` | 管理 MCP 服务器连接 |
| `/export` | 导出对话为 Markdown |
| `/resume` | 恢复历史会话 |
| `/rename` | 重命名当前会话 |
| `/rewind` | 回退到之前的检查点 |
| `/sandbox` | 启用操作系统级沙箱隔离 |
| `/plugin` | 浏览和安装插件 |

## CLI 参数

| 命令 | 说明 |
|------|------|
| `claude -p "提示词"` | 非交互式运行，输出结果后退出 |
| `claude -c` / `claude --continue` | 继续最近的会话 |
| `claude --resume` | 从历史会话列表中选择恢复 |
| `claude --model <模型名>` | 指定使用的模型 |
| `claude --output-format json` | 以 JSON 格式输出结果 |
| `claude --output-format stream-json` | 流式 JSON 输出 |
| `claude --allowedTools "Read,Edit,Bash"` | 限制可用工具（适合批量/CI 场景） |
| `claude --dangerously-skip-permissions` | 跳过所有权限检查（仅在沙箱环境中使用） |
| `claude --verbose` | 调试模式，输出详细信息 |

## 快捷键

| 快捷键 | 说明 |
|--------|------|
| `Esc` | 中断当前思考/执行 |
| `Esc Esc` | 打开 Rewind 菜单，回退到之前检查点 |
| `Shift+Tab` | 循环切换权限模式 / 进入 Plan 模式 |
| `Ctrl+R` | 反向搜索历史提示词 |
| `Ctrl+G` | 在编辑器中打开计划进行编辑 |
| `'` | 直接执行 Bash 命令 |
