## Draw.io

> 免费开源的在线绘图工具，支持流程图、架构图、UML 等各类图表。

[在线使用](https://app.diagrams.net/) | [桌面版下载](https://github.com/jgraph/drawio-desktop/releases)

- 支持 `.drawio` 文件存储在 Git 仓库中
- VS Code 可安装 [Draw.io Integration](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio) 插件直接编辑

## Excalidraw

> 手绘风格的在线白板工具，适合快速草图和头脑风暴。

[在线使用](https://excalidraw.com/)

- 轻量、无需登录即可使用
- 支持实时协作

## ProcessOn

> 国产在线协作绘图平台，模板丰富，上手简单。

[官方网站](https://www.processon.com/)

## PlantUML

> 用纯文本描述 UML 图，适合在代码仓库中维护设计文档。

[官方网站](https://plantuml.com/)

- IntelliJ IDEA 可安装 [PlantUML Integration](https://plugins.jetbrains.com/plugin/7017-plantuml-integration) 插件
- VS Code 可安装 [PlantUML](https://marketplace.visualstudio.com/items?itemName=jebbs.plantuml) 插件

## Mermaid

> Markdown 内嵌图表语法，GitHub / GitLab / Fumadocs 等平台原生支持渲染。

[官方网站](https://mermaid.js.org/)

- 支持流程图、时序图、甘特图、类图、ER 图等
- 无需额外工具，直接在 Markdown 中编写
