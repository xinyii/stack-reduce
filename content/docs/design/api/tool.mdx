## Apifox

> API 设计、开发、测试一体化协作平台，支持自动生成文档、Mock 数据、自动化测试。

[官方网站](https://apifox.com/)

- 支持导入 Swagger/OpenAPI、Postman 等格式
- 内置 Mock 服务，前后端可并行开发
- 支持团队协作和版本管理

## Swagger / OpenAPI

> 业界标准的 API 描述规范，通过注解自动生成接口文档。

[官方网站](https://swagger.io/)

- Java 项目推荐使用 [SpringDoc](https://springdoc.org/)（基于 OpenAPI 3）
- 旧项目常用 [Springfox](https://github.com/springfox/springfox)（基于 Swagger 2）

## Postman

> 老牌 API 测试工具，适合个人调试接口。

[官方网站](https://www.postman.com/)

## YApi

> 开源的接口管理平台，支持 Mock、自动化测试、权限管理，适合私有化部署。

[GitHub 仓库](https://github.com/YMFE/yapi)
