title: 通用库
description: 前端通用依赖库推荐。
---

> 以下库适用于 Web、H5、小程序等多端项目。

## HTTP 请求

- [Axios](https://axios-http.com/) - 基于 Promise 的 HTTP 客户端，支持拦截器、取消请求
- [ky](https://github.com/sindresorhus/ky) - 基于 Fetch 的轻量 HTTP 客户端

## 日期处理

- [Day.js](https://day.js.org/) - 轻量级日期库，API 兼容 Moment.js，体积仅 2KB

## 工具函数

- [Lodash](https://lodash.com/) - 最流行的 JavaScript 工具函数库
- [Radash](https://radash-docs.vercel.app/) - 现代化的 Lodash 替代品，零依赖，TypeScript 优先
- [VueUse](https://vueuse.org/) - Vue 组合式 API 工具集，提供 200+ 实用 Hooks

## 图标

- [Iconify](https://iconify.design/) - 统一图标框架，整合 150+ 图标集
- [Iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库，支持自定义图标项目

## 状态管理

- [Pinia](https://pinia.vuejs.org/) - Vue 官方推荐的状态管理库

## 表单校验

- [VeeValidate](https://vee-validate.logaretm.com/) - Vue 表单校验库
- [Zod](https://zod.dev/) - TypeScript 优先的数据校验库，可同时用于前后端

## 文件处理

- [FileSaver.js](https://github.com/niceFeng/FileSaver.js) - 客户端文件下载
- [SheetJS](https://sheetjs.com/) - Excel 文件读写
- [html2canvas](https://html2canvas.hertzen.com/) - 网页截图

## 富文本编辑器

- [Tiptap](https://tiptap.dev/) - 基于 ProseMirror 的无头富文本编辑器，可高度定制
- [WangEditor](https://www.wangeditor.com/) - 国产轻量级富文本编辑器，开箱即用
