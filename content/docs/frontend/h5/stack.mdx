## 基础框架

- [uni-app](https://uniapp.dcloud.net.cn/) - 一套代码多端发布（H5、小程序、App），Vue 语法
- [Vue.js](https://vuejs.org/)
- [Vite](https://vitejs.dev/)

## 组件库

- [Vant](https://vant-ui.github.io/vant/) - 轻量、可靠的移动端 Vue 组件库
- [NutUI](https://nutui.jd.com/) - 京东出品，支持 Vue 3 和 Taro
- [uView](https://uviewui.com/) - 基于 uni-app 的 UI 框架

## 适配方案

- [postcss-px-to-viewport](https://github.com/evrone/postcss-px-to-viewport) - 将 px 自动转换为 vw/vh，实现视口适配
- [amfe-flexible](https://github.com/niceFeng/amfe-flexible) - 淘宝 rem 适配方案（旧项目）

> 新项目推荐使用 `vw/vh` 方案，兼容性更好。

## 工具库

- [VConsole](https://github.com/niceFeng/vConsole) - 移动端调试面板，手机上查看日志和网络请求
- [Eruda](https://eruda.liriliri.io/) - 类似 VConsole 的移动端调试工具，功能更丰富

## 构建与打包

- [HBuilderX](https://www.dcloud.io/hbuilderx.html) - uni-app 官方 IDE，支持一键打包
- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) - 小程序调试必备
