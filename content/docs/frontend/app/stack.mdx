## 跨平台方案

### uni-app

> 基于 Vue.js 的跨平台框架，一套代码可发布到 iOS、Android、H5、各家小程序。

[官方网站](https://uniapp.dcloud.net.cn/)

- 学习成本低，Vue 开发者可快速上手
- 通过 HBuilderX 或 CLI 构建原生 App
- 插件市场生态丰富

### Flutter

> Google 出品的跨平台 UI 框架，使用 Dart 语言，性能接近原生。

[官方网站](https://flutter.dev/)

- 自绘引擎，UI 一致性好
- 性能优秀，适合对动画和性能要求高的场景
- 学习 Dart 语言有一定成本

### React Native

> Facebook 出品，使用 React 语法开发原生 App。

[官方网站](https://reactnative.dev/)

- React 开发者可快速上手
- 新架构（Fabric + TurboModules）持续优化性能

## 原生开发

| 平台 | 语言 | IDE |
|------|------|-----|
| Android | Kotlin / Java | [Android Studio](https://developer.android.com/studio) |
| iOS | Swift / Objective-C | [Xcode](https://developer.apple.com/xcode/) |

## 混合方案

### Capacitor

> Ionic 团队出品，将 Web 应用打包为原生 App，可调用原生 API。

[官方网站](https://capacitorjs.com/)

- 适合已有 Web 项目快速转 App
- 插件体系完善，支持自定义原生插件
